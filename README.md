# 🏨 HotelHup

### Hotel Property Management System

HotelHup is a web-based hotel management system designed to help hotel teams manage their daily operations in one place. It brings together property, room, guest, reservation, folio, and payment management, reducing the need to rely on disconnected tools and manual workflows.
## ✨ Features

- 🏢 Manage hotel properties and settings.
- 🛏️ Organize rooms and room types.
- 👥 Manage guest information.
- 📅 Create and manage reservations.
- 🧾 Track reservation folios and charges.
- 💳 Record payments and refunds.
- 🧹 Manage housekeeping tasks.
- 📊 View operational reports.
- 🔐 Use JWT authentication and permission-based access controls.
- 💰 Configure rate plans, taxes, cancellation policies, and deposit policies.
